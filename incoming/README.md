# incoming/

New art awaiting the owner, written by `python workbench/intake.py` (never into `assets/`).
Each action is `incoming/<character>/<action>/NN.png` plus `intake.json` (source, method, scale,
alignment, what it would replace, spec). Its report and diagnostics are in `out/incoming/`.
The review page lists it as "new, awaiting owner" next to the action it would replace.
Moving an approved set into `assets/` is the owner's decision and a manual step.
