# 2D Animation Workbench

Tools for inspecting, diagnosing and previewing sprite animation for the Ren point-and-click game (Eiralia).

- `assets/` — frames imported from the earlier project, with `manifest.json` recording each action's status and the owner's feedback. Treat as read-only.
- `tools/import_from_gpt.py` — re-imports those assets from the owner's PC (local only).
- `CLAUDE.md` — the build brief for the workbench prototype.

The workbench itself is not built yet; see `CLAUDE.md`.
