Level runner (not the game)

Plays any level file with every engine feature: screens and doors, hiding spots, objects and puzzles, sequences, emotes, sounds and guard patrols. Click to walk, climb or use; click an item, then an object, to use it. Placeholder shapes; existing art only. Defaults: sandbox/runner.json. URL: ?level=name&x=..&on=.., &draft=1 plays the level editor's unsaved level, &fresh=1 ignores saved progress.
